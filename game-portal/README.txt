Damians Free Tutoring Evolved - Game Portal

Open game-portal/index.html to browse and search the game list. Each game has its own HTML launcher in game-portal/games/.
The Settings button opens the live site settings page in your browser.
The game launcher has a Back to website button in the top-left corner. Open separately is available in the top-right if a game does not work in the embedded player.
Games in the embedded player may have browser storage restrictions. Use Open separately to give a game a better chance to save progress using its own browser storage, if the game supports saving. Saved data normally remains in that game’s browser storage on this device and browser profile; it is not automatically synced or backed up.
Game content and thumbnails are loaded from their configured web servers; this ZIP does not include original game assets and requires an internet connection.
Keep the extracted folder structure intact.
